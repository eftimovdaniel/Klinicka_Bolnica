# Frontend

Frontend слојot е напишан со чист HTML, CSS и JavaScript, без употреба на современи framework-и како React или Angular. Овој избор го прави интерфејсот лесен за разбирање и одржување, без потреба од алатки за компајлирање или управување со зависности. Главните страници (`index.html`, `novosti.html`, `oddel-details.html`) и скриптите (`script.js`, `session.js`, `ai_chat.js`) заедно го градат целиот кориснички интерфејс со кој пациентите, лекарите и администрацијата директно комуницираат во прелистувачот.

Во продолжение е објаснета структурата на страниците, начинот на кој frontend-от комуницира со backend-от преку API повици, како и имплементацијата на AI чат виџетот.
