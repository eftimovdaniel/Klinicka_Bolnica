# Општо за системот

Овој дел дава општа слика за системот, пред да навлезете во конкретни технички детали распределени низ останатите делови од документацијата. Тука ќе најдете преглед на целиот проект и неговата намена во контекст на болницата, архитектурата и начинот на кој се поврзани сите клучни компоненти, технологиите на кои системот се темели, како се инсталира од нула на ново опкружување, и како се конфигурира за стабилна и безбедна работа во развојна или продукциска средина.

Доколку сте нов во проектот, овој дел е најдобра почетна точка — дава целосен контекст пред да навлезете во специфичните делови за Backend, Frontend или деплојмент.
