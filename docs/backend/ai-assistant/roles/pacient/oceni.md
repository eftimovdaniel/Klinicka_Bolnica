# Пациент: Прегледи и оцени

Пациентот може да ги прегледа своите минати и идни прегледи, да остави оцена за **завршен** преглед и да ја избрише дадената оцена — сè преку разговор. Сите функции бараат најавен пациент и работат само со неговите записи (по `email`).

## 1. Преглед <a id="1-pregled"></a>

| Намера | Фајл | Дејство во база |
|--------|------|-----------------|
| `moi_pregledi` | `moi_pregledi.py` | `SELECT` термини по статус/период/датум |
| `oceni_pregled` | `oceni_pregled.py` | `INSERT … ON DUPLICATE KEY UPDATE` во `Pregled_feedback` |
| `trgni_ocena` | `trgni_ocena.py` | `DELETE` од `Pregled_feedback` |

> Оцена може да се остави **само за прегледи со статус „завршен"** — статусот го поставува лекарот преку [`zavrshi_pregled`](../lekar/raspored.md). Затоа двете улоги се поврзани.

***

## 2. Мои прегледи (`moi_pregledi`) <a id="2-pregledi"></a>

Листа на термините на пациентот со резиме по статус. Groq извлекува период (`denes`, `idni`, `minati`, `site`), конкретен датум, број на резултати и статус/категорија. За завршените прегледи се покажуваат и дијагнозата и терапијата.

```python
# backend/ai/pacient/moi_pregledi.py (избор) — резиме по статус
br_zakazan = sum(1 for r in rows if r.get("status_pregled") == "закажан")
br_zavrsen = sum(1 for r in rows if r.get("status_pregled") == "завршен")
br_otkazan = sum(1 for r in rows if r.get("status_pregled") == "откажан")
```

### Реален излез

```text
Твои прегледи (3)
Закажани: 1 | Завршени: 1 | Откажани: 1

- 16.06.2026 09:30 – Марко Петров [закажан]
- 02.06.2026 11:00 – Марко Петров [завршен]
   Дијагноза: Мигрена
   Терапија: Аналгетик 2x дневно
- 20.05.2026 08:30 – Ана Стоилова [откажан]
```

> Кога нема резултати: „Немаш прегледи кои одговараат на твоето барање." (или со датум: „Немаш прегледи на 16.06.2026.").

## 3. Оцена за преглед (`oceni_pregled`) <a id="3-oceni"></a>

Пациентот остава оцена (1–5) + опционален коментар за завршен преглед. Groq извлекува оцена, коментар, лекар и датум. Записот е **upsert** — повторна оцена за истиот термин ја ажурира претходната.

```python
# backend/ai/pacient/oceni_pregled.py (избор)
cur.execute("""
    INSERT INTO Pregled_feedback (termin_ID, ocena, komentar)
    VALUES (%s, %s, %s)
    ON DUPLICATE KEY UPDATE
      ocena = VALUES(ocena),
      komentar = VALUES(komentar),
      datum_na_ocena = CURRENT_TIMESTAMP
""", (termin_id, ocena, komentar))
```

### Реален излез

```text
Благодариме за оцената!

Лекар: Д-р Марко Петров
Специјалност: Кардиологија
Датум: Понеделник, 02.06.2026 во 11:00
Оцена: ★★★★★ (5/5)
Коментар: Беше одличен
```

Други можни одговори:

| Ситуација | Одговор |
|-----------|---------|
| Оцена надвор од 1–5 | „Не разбрав која оцена сакаш да дадеш. Кажи број од 1 до 5." |
| Нема завршен преглед | „Не најдов завршен преглед што одговара…" |
| Повеќе завршени прегледи | Листа (со ознака „(веќе оценет)") + бара прецизирање |
| Веќе постоела оцена | „Оцената е ажурирана!" наместо „Благодариме за оцената!" |

## 4. Бришење оцена (`trgni_ocena`) <a id="4-trgni"></a>

Брише претходно дадена оцена (физички `DELETE` од `Pregled_feedback`). Се бараат само завршени термини на пациентот што **имаат** оцена (`INNER JOIN`).

```python
# backend/ai/pacient/trgni_ocena.py (избор)
cur.execute(
    "DELETE FROM Pregled_feedback WHERE feedback_ID = %s",
    (feedback_id,))
```

### Реален излез

```text
Оцената е избришана!

Лекар: Д-р Марко Петров
Специјалност: Кардиологија
Датум: Понеделник, 02.06.2026 во 11:00
Избришана оцена: 5/5

Можеш повторно да оцениш ако сакаш: „Оцена [1-5] за прегледот кај д-р Петров".
```

> Ако има повеќе оценети прегледи → листа со ѕвезди (`★★★★☆`) и бара прецизирање. Ако нема ниту еден → „Не најдов оценети прегледи што одговараат…".

## 5. Пробај <a id="5-probaj"></a>

**Мои прегледи** преку `POST /ai-chat/ask`:

```json
{
  "prasanje": "Кои се сите мои прегледи?",
  "pacient": { "pacient_ID": 1, "email": "daniel@example.com" },
  "kontekst": null
}
```

**Оцена за преглед**:

```json
{
  "prasanje": "Оцена 5 за прегледот кај д-р Петров — беше одличен",
  "pacient": { "pacient_ID": 1, "email": "daniel@example.com" },
  "kontekst": null
}
```

**Бришење оцена**:

```json
{
  "prasanje": "Тргни ја оцената за прегледот кај д-р Петров",
  "pacient": { "pacient_ID": 1, "email": "daniel@example.com" },
  "kontekst": null
}
```

> Оцена и бришење оцена работат **само** за прегледи со статус „завршен" — ако нема таков, асистентот објаснува зошто и бара да се прецизира лекар и/или датум.

> **Тестирај го овде →** [POST `/ai-chat/ask`](../../../api/ai-chat.md#3-ask)
