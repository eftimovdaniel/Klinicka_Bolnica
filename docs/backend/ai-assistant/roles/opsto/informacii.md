## 2. Работно време, локации, контакти (`bolnica_info`) <a id="2-info"></a>

Трите намери ги опслужува `bolnica_info.py`, читајќи од `backend/data/bolnica_info.json`. Ако прашањето спомнува конкретен оддел, Groq го извлекува и враќа само неговото време/локација; инаку се прикажува сè.

### Реален излез (работно време)

```text
Работно време на Клиничка Болница Штип:

Понеделник – Петок: 08:00 – 16:00
Сабота и Недела: само Итна помош

По оддели:
- Кардиологија: 08:00 – 15:00
- Лабораторија: 07:00 – 14:00
```

### Реален излез (контакти, итно)

```text
Итна помош:

Телефон: 194
Локација: Главна зграда, приземје, главен влез
Достапна: 24 часа, 7 дена во неделата
```

> Контактите имаат и брза детекција на „итно" (без AI) — ако прашањето спомне итност, веднаш се враќаат деталите за Итна помош.

## 3. Подготовка за преглед (`faq_pregled`) <a id="3-faq"></a>

Често поставувани прашања за подготовка („дали на гладно", „што да понесам"). Одговорот комбинира фиксни ставки од извор и, по потреба, AI за поприроден текст.

```text
Напишете го прашањето (на пр. дали на гладно, што да понесам на преглед).
```

> Темите се мапираат на подготвени одговори; AI се користи само за форматирање, не за измислување медицински совети.

***

## 4. Резултати од тестови (`rezultati_testovi`) <a id="4-rezultati"></a>

Кога се очекуваат резултати од тестови. Логиката е детерминистичка — препознава тип на испитување и враќа очекуван рок, со насочување кон лабораторија/рецепција за точен датум.

```text
рокот зависи од типот на тест. Рецепција (032/ 605-001) или лабораторијата имаат точен датум.
```

## 5. Новости (`novosti_rezime`) <a id="5-novosti"></a>

Краток преглед на последните објави од табелата `Novosti`.

```python
# backend/ai/opsto/novosti_rezime.py (избор)
cur.execute("SELECT naslov FROM Novosti ORDER BY ... LIMIT ...")
```

### Реален излез

```text
Последни објави на сајтот:

• Нов МРТ апарат во болницата
• Бесплатни прегледи за крвен притисок
• Известување за работно време за празници
```

## 6. Дежурства (`pregled_dezurstvo`) <a id="6-dezurstva"></a>

Преглед на **идни** дежурства — за цел тим или за конкретен лекар. Чита од `Dezurstva` и означува кој е „сега на дежурство".

```python
# backend/ai/opsto/pregled_dezurstvo.py (избор)
SELECT datum, oddel, vreme_od, vreme_do  -- (+ name/surname за конкретен лекар)
FROM Dezurstva WHERE datum BETWEEN ... ORDER BY datum, vreme_od
```

### Реален излез

```text
Идни дежурства на лекарите:

Среда, 17.06.2026:
• д-р Марко Петров (Кардиологија) — Ургентен центар — 08:00–20:00  ← сега на дежурство

Четврток, 18.06.2026:
• д-р Ана Стоилова (Неврологија) — Ургентен центар — 08:00–20:00
```

> За конкретен лекар: „Дежурства на д-р Марија Хубрева". Ако нема: „Нема закажани идни дежурства во системот." (директорот ги додава преку [админ панелот](../direktor/dezurstva.md)).

## 7. Пробај <a id="7-probaj"></a>

**Работно време / контакт**:

```json
{ "prasanje": "Кога работите?", "pacient": null, "lekar": null, "kontekst": null }
```

**Дежурства**:

```json
{ "prasanje": "Прикажи ги дежурствата на лекарите", "pacient": null, "lekar": null, "kontekst": null }
```

**Новости**:

```json
{ "prasanje": "Што има ново?", "pacient": null, "lekar": null, "kontekst": null }
```

> Сите овие работат и за гости (`pacient` / `lekar` = `null`).

> **Тестирај го овде →** [POST `/ai-chat/ask`](../../../api/ai-chat.md#3-ask)
